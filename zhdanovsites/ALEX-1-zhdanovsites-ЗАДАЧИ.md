# Alex 1: новые разделы zhdanovsites.com

Это готовые файлы от Mike Japan Claude. Существующие файлы сайта не меняются, все новые части лежат отдельно. Исключение одно: в главную страницу добавляется одна строка.

Где лежат файлы:
- в архиве `zhdanovsites-addons.zip` (рядом с этим файлом);
- в репозитории github.com/zhdanovsites/zhdanov-core, папка `zhdanovsites/`.

Обязательно на всём сайте: 360 px, Lighthouse 95+, axe 0 ошибок, без длинного тире «—», без придуманных фактов. Контакты для РФ: сначала MAX и телефон, потом Telegram.

## 1. Положить файлы в проект сайта (10 минут)

Пути указаны от корня проекта Cloudflare Pages: там, где лежат `index.html` и папка `functions/`.

| Файл из архива | Куда положить | Что это |
|---|---|---|
| `audit2.js` | `/audit2.js` | Живой аудит: цель, шаги, оценка 0–100, нейросети, деньги, «Вы и 3 конкурента», «Поделиться» |
| `functions/api/geo.js` | `/functions/api/geo.js` | Проверка «Видят ли вас Алиса и нейросети» (адрес `/api/geo`) |
| `functions/api/tgbot.js` | `/functions/api/tgbot.js` | Telegram-бот аудита (адрес `/api/tgbot`) |
| `style/index.html` | `/style/index.html` | Квиз «Подберите стиль сайта» (адрес `/style/`) |
| папка `vs/` целиком | `/vs/` | «Сейчас и после»: слайдер старого и нового сайта (адрес `/vs/?c=bkz`) |

Ничего из существующего (`/api/check`, `/api/verify`, `style.css`) не трогать.

## 2. Одна строка в русскую главную (2 минуты)

В `index.html` (русская версия) **перед `</body>`, после основного скрипта сайта**:

```html
<script src="/audit2.js" defer></script>
```

На английской версии ничего не добавлять: скрипт сам выключается, если язык страницы не ru.

## 3. Telegram-бот аудита (15 минут, нужен Алексей)

1. **Алексей** создаёт бота в @BotFather: `/newbot`. Имя «Проверка сайта · Zhdanov Sites», адрес например `@zhdanov_audit_bot`. BotFather выдаст токен. Аккаунты и токены создаёт и вводит только Алексей.
2. В Cloudflare: Pages → проект сайта → Settings → Variables and Secrets. Добавить три переменные, тип **Secret**:
   - `TG_BOT_TOKEN`: токен нового бота;
   - `TG_SECRET`: любая длинная строка из букв и цифр (например 40 символов);
   - `TG_NOTIFY`: `205949795`. Это чат Алексея, туда будет приходить «кто что проверил». Перед этим Алексей должен нажать Start в новом боте.
3. Сделать redeploy, чтобы переменные подхватились.
4. Открыть в браузере `https://zhdanovsites.com/api/tgbot?setup=ЗНАЧЕНИЕ_TG_SECRET`. Ответ `{"ok":true,...}` значит, что бот подключён.
5. Проверить: написать боту `/start`, потом `belokurov.ru`. Через 20–40 секунд придёт оценка, 3 проблемы и кнопки «Полный отчёт», «Обсудить с Алексеем», «Подобрать стиль».

Отдельный бот нужен потому, что @zhdanov_reports_bot уже служебный (бэкапы и отчёты) и не должен быть публичным.

MAX-бот добавим позже по тому же принципу, когда будет доступ к платформе MAX для ботов.

## 5. Исправить сам zhdanovsites.com по новой проверке «нейросети» (20 минут)

Сейчас сайт получает около 75/100. Чтобы стало 95+:
1. **Телефон текстом** в подвале (не только в кнопке или ссылке), в формате +7 …
2. **Ссылка на карточку в Яндекс Картах или 2ГИС**, если она есть. Если карточки нет, Алексею стоит её завести: это бесплатно и сильно помогает Алисе.
3. **Файл `/llms.txt`** в корне. Пример:
   ```
   # Zhdanov Sites
   > Студия Алексея Жданова: сайты на WordPress и без него, редизайн, аудит, сопровождение. Работаем по России и за рубежом.

   ## Главное
   - [Бесплатная проверка сайта](https://zhdanovsites.com/#check)
   - [Подбор стиля сайта](https://zhdanovsites.com/style/)
   - [Работы](https://zhdanovsites.com/#work)
   - [Статьи](https://zhdanovsites.com/#articles)
   - [Политика конфиденциальности](https://zhdanovsites.com/privacy)

   ## Контакты
   - Telegram: https://t.me/ZhdanovOfficial
   ```
   Перед публикацией дописать телефон и MAX: их знает Алексей. Факты не придумывать.
4. В разметку Organization (JSON-LD) добавить `telephone` и `sameAs` (MAX, Telegram, карточка на картах).

## Как добавить новое «Сейчас и после» для клиента

1. Сделать 4 скриншота, первые экраны, в WebP до 100 КБ:
   - `img/<slug>-old-d.webp` и `img/<slug>-new-d.webp`: 1280×800;
   - `img/<slug>-old-m.webp` и `img/<slug>-new-m.webp`: 390×844.
2. Скопировать `vs/data/bkz.json` в `vs/data/<slug>.json` и заменить тексты и цифры. Цифры только реальные, из замеров.
3. Ссылка для клиента: `https://zhdanovsites.com/vs/?c=<slug>`.
