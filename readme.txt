Плагин-компаньон «Темы Жданов» (Zhdanov Sites): разделы сайта, запись, оплата, закон РФ, SEO. Всё важное живёт в плагине и переживает смену темы.

== Описание ==
Разделы включаются галочками (Жданов → Настройки → Разделы сайта): Афиша, Услуги, Отзывы, Альбомы, Каталог, Расписание и онлайн-запись, Курсы с закрытыми уроками, Специалисты, Меню, Филиалы, Акции, Туры, Залы, Книги, Вакансии, Документы, Недвижимость.

Инструменты: Пресет ниши (14), Рецепт сайта (перенос и автокопия), Дизайн из концепта, Здоровье сайта, Переезд (301 и импорт CSV), Школа (сведения об ОО).

Закон и безопасность: cookie 152-ФЗ, Метрика после согласия, карты и видео по клику, шрифты без Google, реквизиты продавца, оферта, плашка «противопоказания», версия для слабовидящих, базовая защита входа.

Оплата: ЮKassa и Т-Банк (чек 54-ФЗ), сертификаты, пожертвования. Заявки: почта (SMTP Яндекс/Mail.ru), Telegram, список в консоли.

== Установка ==
Плагины → Добавить → Загрузить → zhdanov-core.zip → Активировать. Затем тема «Тема Жданов». Подробно: ИНСТРУКЦИЯ MIKE 2.md.

== Удаление ==
Без галочки «При удалении плагина стереть всё» данные сохраняются.
